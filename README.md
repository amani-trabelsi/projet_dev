# Projet PDL — Client-Serveur

## Présentation

Ce dépôt contient le projet de développement client-serveur consacré à la gestion, au traitement et à la comparaison d’images.

## Structure du dépôt

- `besoins (1).tex` : document décrivant les besoins du projet.
- `export (5)/pdl-client-serveur/` : code source de l’application.
  - `frontend/` : interface utilisateur développée avec Vue.js 3, Vite et Tailwind CSS.
  - `backend/` : serveur développé en Java avec Spring Boot.
  - `README.md` : documentation détaillée de l’application.

## Technologies

- Vue.js 3
- Vite
- Tailwind CSS
- Java 17
- Spring Boot
- Maven
- PostgreSQL
- pgvector

## Lancement du projet

Consultez le [README détaillé de l’application](export%20%285%29/pdl-client-serveur/README.md) pour les instructions d’installation, de configuration et de lancement du frontend et du backend.
